# Паразитологія котів і собак в Україні

Прототип інтерактивного довідника паразитів котів і собак за системами органів.

- План проєкту: [PLAN.md](PLAN.md)
- Список задач: [TODO.md](TODO.md)
- Демо: https://ezavgorodniy.github.io/parasitology/

## Що є в прототипі

- Умовна схема кота та собаки: наведення або натискання на систему органів показує паразитів.
- Каталог паразитів і сторінка кожного паразита.
- Демо-дані в `src/data/parasites.ts` (потребують перевірки фахівцем).

## Локальний запуск

Потрібен Node.js 22+.

```shell
npm ci
npm run dev        # http://localhost:3000
```

## Збірка статичного сайту

```shell
npm run build      # результат у ./out
```

Папку `out` можна викласти на будь-який статичний хостинг (nginx, Apache тощо) у корінь сайту.
Якщо сайт живе в підпапці, задайте її під час збірки:

```shell
PAGES_BASE_PATH=/parasitology npm run build
```

## Деплой

Кожен пуш у `main` автоматично збирає сайт і публікує на GitHub Pages
(`.github/workflows/deploy.yml`).
